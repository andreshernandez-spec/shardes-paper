\section{One implementation for \mbox{every} variant}
\label{sec:instrument}

The library is written in JAX. The computation is written once for all devices, with
annotations that divide the population among them, and the compiler turns it into a
program for each device, including the communication between them
\citep{jax2018,gspmd2021}. It generates the perturbations, evaluates the candidates and
reconstructs the update, for every perturbation design under both placements. Every
device holds a complete copy of the model. Two properties of the implementation matter
for the measurements.

\paragraph{The population stays fixed.} A candidate's random seed depends only on its index
in the population, not on the device that evaluates it. Every device count therefore
evaluates the same perturbations, and both placements reconstruct the same update. With the
fitness scores held fixed, the updates computed for Qwen2.5-0.5B on one and on eight A100s
differ by $6.3\times10^{-6}$ relative to their size, measured over all parameters
(Appendix~\ref{sec:implementation}).

\paragraph{Low-rank perturbations stay factored.} A layer computes
$x(W+\sigma UV^\top/\sqrt r)^\top$ as
$xW^\top+((xV)U^\top)\sigma/\sqrt r$. The first term is one matrix multiplication of all
candidates' inputs with the shared weights $W$; each candidate then adds its own low-rank
correction and keeps its own activations. No candidate's full noise matrix is ever formed.
A model must route its matrix multiplications and embedding lookups through the library's
layers, so an existing model has to be adapted.
