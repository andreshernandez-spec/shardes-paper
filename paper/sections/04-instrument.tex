\section{A shared implementation}
\label{sec:instrument}

The library is written in JAX. The computation is written once for all devices, with
annotations that divide the population among them, and the compiler turns it into a
program for each device, including the communication between them
\citep{jax2018,gspmd2021}. It generates the perturbations, evaluates the candidates and
reconstructs the update, for every perturbation design under both placements. Every
device holds a complete copy of the model. Two properties of the implementation matter
for the measurements.

\paragraph{The population stays fixed.} For a fixed run seed and generation, a
candidate's perturbation depends on its population index, independently of the device
that evaluates it. Changing device count preserves the perturbations. Given the same
fitness scores, both placements compute the same mathematical update, with possible
differences from floating-point rounding. As a check across device counts, we computed
Qwen2.5-0.5B updates on one and eight A100s with the fitness scores held fixed. The updates
have a relative error of $6.3\times10^{-6}$, measured over all parameters together
(Appendix~\ref{sec:implementation}).

\paragraph{Low-rank perturbations stay factored.} For inputs $x$ and a weight matrix
$W$, a layer computes $x(W+\sigma UV^\top/\sqrt r)^\top$ as
$xW^\top+((xV)U^\top)\sigma/\sqrt r$. On each device, the local candidates' inputs are
batched against the shared weights $W$; each candidate adds its own low-rank correction
and retains its own activations. No candidate's full noise matrix is ever formed. To use
low-rank perturbations, matrix multiplications and embedding lookups involving perturbed
weights must go through the library's layers, so existing model code needs adaptation.
