# What the drivers, the table scripts and the test suite need. One line in this file is
# load-bearing: the shardes pin. A result is reproduced by checking this repository out at
# the commit its record stamps and installing from here, so the library commit is a
# function of this repository's commit and nobody types it by hand. `harness.capture_env`
# records which shardes actually ran, as a check on exactly that.
#
# To develop against a local checkout of the library instead:
#     pip install -e ../shardes     (or wherever the clone is)
# and the record will say source "checkout", with that checkout's commit and dirty flag.
#
# The pin is a commit and not a tag, because a tag can be moved and a commit cannot. When
# the commit is a release, the tag is named beside it, and CI checks that the two agree.
#
# An accelerator run installs jax for its platform on top, as before:
#     pip install -U "jax[cuda12]>=0.11"     or     "jax[tpu]>=0.11"
