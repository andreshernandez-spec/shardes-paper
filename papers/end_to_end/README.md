# End to end: ES fine-tuning against released RL checkpoints

The second paper. It retrains open models with shardes' evolution strategies on exactly
the data a released RL checkpoint was trained on, from the same start, and compares the
two at matched rollouts.

No manuscript yet. The plan is `docs/end_to_end/00-plan.md`; the experiments and their
results live in `experiments/end_to_end/`.
